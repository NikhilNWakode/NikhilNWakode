# 🧩 How I Build

I don't start with:

> *"Which technology should I use?"*

I start with:

> *"What problem am I actually trying to solve?"*

Then:

```text
             ┌─────────────┐
             │   PROBLEM   │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │  UNDERSTAND │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │  PROTOTYPE  │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │    BUILD    │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │   MEASURE   │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │   ITERATE   │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │    SHIP 🚀  │
             └─────────────┘



This is a good differentiator because it's about **how you think**, not what libraries you've memorized.
```
